# Workouts Feature

Owns active workout sessions, set entries, exercise order, notes, and completed workout summaries.

- Weight boxes contain a horizontal swipe ruler with a fixed marker and 0.5 lb snapping. Tick lengths distinguish half-pounds, whole pounds, 5 lb and 10 lb; ten-pound labels stay inside the box. Native `expo-haptics` gives tick feedback where the device permits it. Tap the number for exact entry, or use accessible increment/decrement and keyboard arrows. Without eligible history, blank weights stay unchosen until an action; mounting/copying/prefilling does not round existing decimals. Ruler bounds match actual-set validation (0–10,000 lb).
- Horizontal gestures follow the finger continuously until release, including direction changes, and retain their initial movement and selected ticks even if native scrolling interrupts them; vertical scrolling remains available. ±5/±10 lb buttons handle larger adjustments without changing the half-pound scale. Controlled updates reconcile in a synchronous layout effect, preventing an earlier tick's delayed effect from ending a current drag. **Last saved** and **Recent average** text and conditional reuse buttons are below all sets. The web logger scroll container opts out of browser scroll anchoring, keeping the active scale in place even after a footer button was focused.
- With coaching on or off, `getSavedExerciseHistory` reads actual sets from active and completed sessions without a 90-day/120-session cutoff. `weightHistory.ts` defaults untouched rows to the final valid working rep set of the newest matching saved exercise entry, keeping exact decimals and zero. Save timestamps determine recency; persisted exercise order resolves same-session timestamp ties. Private notes, program targets, warm-ups, timed/invalid/future sets and incompatible load contexts do not set the baseline. Catalog IDs match exactly; custom names use trimmed case-insensitive matching with exact-ID fallback for unnamed legacy entries.
- Last saved work takes priority over untouched program starting loads. Manual choices, an open exact editor, explicit same-number confirmation, clearing and copied rows remain protected from delayed reads. `WeightRuler.onInteract` marks intent before value changes; mounting, controlled updates and vertical scrolling do not mark interaction. Prefill happens once; refresh and coach apply/undo retain draft measurements and notes.
- **Recent average** remains an optional completed-workout shortcut: the rep-weighted mean (`sum(weight × reps) / sum(reps)`) from the latest three eligible completed sessions within 90 local calendar days, rounded to 0.5 lb. **Use recent … lb for all sets** explicitly applies it when current weights differ. `getCoachHistory` remains completed-only; saving an exercise in an unfinished session does not become coaching/progression evidence.
- Without a saved working weight, retain a program load or use **Select weight** for exact entry. **Use … lb for empty sets** fills blanks after choosing the first weight. Weight reuse never changes history, schemas, notes, schedules or the saved program, and never saves a result automatically.
- Effort fits in one optional segmented row: **Skip / Easy / Right / Hard**. Right stores the existing moderate/about-right value; missing effort stays unknown. Warm-ups, duration targets, copied measurements and notes retain their existing behavior.
- **Load coaching** is one on/off switch for the whole session. Programs save its default; session overrides survive reload/resume without editing the template or completed results. Native schema 10 adds a nullable session flag; web keeps its current key/marker. Existing explicit load settings remain stored but no longer have per-exercise setup controls. Without those settings, reviewed shorter-session proposals preserve manual weights/reps/time/notes and do not manufacture numeric load advice.

- Every actual rep or timed set has a collapsed **Add note to self (optional)** editor. Multiline notes are private and limited to 1,000 characters; saving without a note requires no extra action. Copying the last set keeps its measurements but starts with no note. Coach apply/undo and changed suggestions retain typed notes.
- **View sets and notes** in the active log, or tap a recent completed session on Today, to review actual sets and add/edit/clear notes. Saved edits use explicit **Save note**, **Cancel** and **Clear note** actions. Collapsing either section keeps an unsaved draft; failed saves retain the original stored note and offer retry.
- Notes persist offline on SQLite and web storage with no account required. Native schema 9 adds nullable `set_entries.note` to existing schema-6/7/8 data without another reset. Blank text becomes null; only the selected set's note and update timestamps change. Notes are excluded from coaching inputs and social publishing.

- **Exit session** is visible at the top of the session log. An empty unfinished workout is cancelled without recording completion or rest, so a fresh workout can start. Planned targets are not saved results; cancelling their empty session leaves the program unchanged. Workouts with logged exercises return to Today with **Resume workout**, preserving their results and plan snapshot. Failed cancellation keeps the session open for retry; storage guards and serialized writes protect concurrent saves and completed/nonempty sessions.
- Today follows the active program's current local weekday/cycle day when starting a workout, with its planned exercises and targets ready to log. Rest days and future program starts use manual tracking.
- **Start without program** offers a manual workout on a scheduled training day without changing the active program. Unfinished sessions always resume with their original snapshot. **Change or deactivate program** opens Programs; deactivation returns future starts to normal tracking.
- Schedule and streak refresh together on focus, resume, date rollover and successful training writes, with stale-request protection. Planned exercises do not count as actual sets; only completed sessions earn workout streak credit and cancel the day's remaining reminders.
